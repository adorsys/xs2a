= Roadmap

Starting the 12-th of October 2023 XS2A-core Team is providing development within two branches:

*Stable branch 16.x*

Stable branch will contain bugfixing and possibly necessary changes to support mandatory endpoints defined by Berlin Group NextGenPSD2 Spec 1.3.12 with all Errata files. Will be supported at least till 24.08.2024.

*Development branch 17.x*

Development branch is oriented on implementation of new features and optional endpoints.
No backward compatibility with 16.x is guaranteed. Will be released as Stable version 18.x in the nearest future.
