### Migration from berlin group spec: 1.3.12 to 1.3.15.

* Added regulatory clarifications, including townName usage and timestamp offset guidance.
* Added missing ISO20022 Status Reason Code
* Introduced optional extended status endpoint for JSON bulk payments (aligned with pain.002).
* Added categoryPurposeCode at bulk level for JSON payment initiation.
* Added cardAcceptorName to card transaction reports.
* Added creditorNameConfirmation attribute and  added new codes: RVCM, RVNC, RCVC .
* Added  startDateTime and endDateTime attributes for Periodic-payment.
* Added full structured address support for involved parties.
* Updated bulk status attributes: transactionStatus → groupStatus, singleTransactionStatus → transactionStatus (single payment).
* Added Group Payment Status Code list (ISO20022).
* Added VOP-specific data elements to the data overview.
* Added originalTransactionInformationAndVopStatus parameter.
* Documented the impact of VOP services on Payment Initiation requests/responses and extended status flows.
* Added optional "Cancel-PIS" OAuth2 scope prefix for payment cancellation authorisation.
